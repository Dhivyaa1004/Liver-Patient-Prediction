

# 🩺 Liver Disease Prediction System

![Learn-About-Hepatitis-Types-Symptoms-and-How-to-Prevent-It-730x324](https://github.com/user-attachments/assets/5311eade-279d-4d7e-ba7e-a95652df2c02)

A Machine Learning and Streamlit based web application that predicts liver disease using patient medical parameters.

## 🚀 About The Project

This project is developed to analyze liver patient medical records and predict whether a patient is affected by liver disease.

The system uses a complete Machine Learning Pipeline with preprocessing, feature engineering, model training, and deployment.

The web application is developed using Streamlit for interactive prediction and FastAPI for API integration.

## 📊 Input Features

- Age
- Gender
- Total Bilirubin
- Direct Bilirubin
- Alkaline Phosphotase
- Alamine Aminotransferase
- Aspartate Aminotransferase
- Total Proteins
- Albumin
- Albumin and Globulin Ratio
